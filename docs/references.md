# Sources and attribution

- [CMU Deep Learning Systems](https://dlsyscourse.org/): public educational structure linking autodiff, operators and training; no student solutions copied.
- [Stanford CS231n](https://cs231n.github.io/assignments2023/assignment2/): background on vectorized backpropagation and optimization.
- Kingma and Ba, [Adam](https://arxiv.org/abs/1412.6980),2014: adaptive moments and bias correction.
- [PyTorch autograd mechanics](https://docs.pytorch.org/docs/stable/notes/autograd.html): independent reference, not this engine's backend.
- [Fashion-MNIST author repository](https://github.com/zalandoresearch/fashion-mnist): original files, advertised checksums and terms.
- [NumPy](https://numpy.org/doc/stable/): array operations and BLAS-backed matrix multiplication.

The project implements established methods with AI assistance. Its own components are graph construction, VJPs, traversal, lifecycle checks, models, optimizer loops, data checks, metrics and experiment organization. No original learning algorithm, handwritten BLAS or framework-equivalent coverage is claimed. Dataset and dependency licenses remain separate from the code license.
